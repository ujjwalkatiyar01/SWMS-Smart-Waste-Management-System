# Intro assets

`swms-cinematic.webp` is the served lossless derivative (1,239,930 bytes) of the original PNG below. Decoded RGB pixels were compared and are identical. The original PNG is retained for provenance.

- `swms-cinematic.png`: exact second image supplied by the project owner in the 2026-10-28 request. Preserved unchanged. The individual letters, recycling bin, arrow, city/nature imagery, tagline and reflection are revealed using CSS masks; they are not independent 3D meshes. The eight-frame storyboard is a reference only and is not served as an animation background.
- `earth-day.jpg`: downloaded 2026-10-28 from https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg .
- `earth-clouds.png`: downloaded 2026-10-28 from https://threejs.org/examples/textures/planets/earth_clouds_1024.png .
- Earth source collection: https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets . Keep the source provenance with the local copies. The Three.js library is MIT licensed; see the installed package's LICENSE. No browser request to the source site is made at runtime.

Only the planet is rendered as live 3D. CSS leaves/orbits, the light sweep, and the photo's reflective floor simulate the other effects. No 3D logo model was supplied.
